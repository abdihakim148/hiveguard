I'm **Abdihakim Osman** — a software engineer in Kenya, building tools for education and developer infrastructure.

Right now I'm running two projects:

**[EduXal](https://eduxal.com)** — AI-powered school management and assessment for private schools in Kenya. I'm the founder and the only engineer. Architecture, backend, frontend, infra — all me.

**[HiveGuard](https://github.com/abdihakim148/hiveguard)** — A hexagonal authentication system in Rust. Pluggable adapters for databases, email, and token strategies (JWT or PASETO), with OAuth2.0 and OpenID Connect support. I built it because every auth library I tried was either too opinionated or too half-baked.
